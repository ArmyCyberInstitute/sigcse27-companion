Slide Content
  • Each slide must use a clean, consistent layout.
  • Most slides should include a visual element. Instead of generic “graphic goes here,” provide a clear visual placeholder description (e.g., “diagram of generals with conflicting orders”) that could be used by an illustrator or image generator.
  • Use different modalities across the lecture:

    • Narrative slides (1–2 sentences + image).
    • Interactive slides (questions, polls, Q&A).
    • Avoid monotonous runs of bullet-point slides.

Instructor Notes
Each slide must contain a ::: {.notes} block with the following sections in order:
  1.  Key Points – concise takeaways for students.
  2.  Instructor Notes and Script – 3–5 paragraphs with context, detail, and analogies. Plain text only, no markdown inside. Accessible at ~8th grade level. Must connect to the visual.
  3.  Script – Suggested dialogue, simplified and explanatory.
  4.  References – Clickable markdown list of primary sources.
