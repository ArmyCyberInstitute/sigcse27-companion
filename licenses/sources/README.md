# Solidity compiler source

`solidity_0.8.26.tar.gz` is the official Solidity 0.8.26 source release accompanying `demos/ethereum_lab/frontend/public/vendor/solc/bin/soljson-v0.8.26+commit.8a97fa7a.js`.

- Release: [Solidity 0.8.26](https://github.com/ethereum/solidity/releases/tag/v0.8.26)
- Compiler license: [GNU GPL version 3](../GPL-3.0.txt)
- Build instructions: `docs/installing-solidity.rst` and the scripts in the source archive

The compiler and its source carry their upstream licenses. The JavaScript wrapper has a separate MIT license at `demos/ethereum_lab/frontend/public/vendor/solc/LICENSE`.
